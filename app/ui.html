Tools

1Organize photos
Copies photos and videos from your folders into the library, sorted by type, year and month. Skips exact duplicates.

          

        
2Convert iPhone photos
Makes a JPEG copy of every HEIC photo, filed by date. The HEIC originals stay until you delete them.

          

        
3Smart tags
AI recognizes beaches, birthdays, Christmas, pets, documents and more. First run downloads a ~350 MB model.

          

        
4Find people
Detects faces and groups the same person together, then you name them on the People page.

          

        
5Find places
Reads the location stored in photos taken with location turned on and shows the nearest town, like “Gardiner, Montana”. Worked out on this computer; nothing is sent over the internet.

User guide
Short and simple. Click a heading to open it. Print this guide

      

        
Getting started (3 steps)

          
  1. Tell Memory Lane where your photos are. Pick every folder that has photos or videos, and choose where the clean library should go (a folder inside iCloud Drive syncs to your phone). You do this on the first screen, or later in Settings.
    2. 
          
  2. Click “Organize everything” on Home. It copies your photos into the library, sorted by year and month, skips exact duplicates, converts iPhone photos, adds smart tags, finds places and finds faces.
    3. 
          
  3. Name the people. Open People and type a name under each face group.

          
Your original photos are never changed, moved or deleted. Memory Lane only makes copies.

        
What each page is for
    
          
  • Home: your totals, the big Organize button, and anything waiting for you. Click the Photos number to see everything as small pictures.
    • 
          
  • Photos: search, filter and open your pictures. Select several to tag, rename, move or delete them.
    • 
          
  • People: name the faces Memory Lane found.
    • 
          
  • Look-alikes: photos that are almost the same as one you already have, set aside so you can choose.
    • 
          
  • Tools: the same steps as Organize everything, one at a time, plus a safety check.
    • 
          
  • Settings: your folders, file naming and the automatic weekly run.

        
Name the people
    
          
  1. Open People. Each card is one person (or a few people who look alike).
    2. 
          
  2. Click the box under the faces. Pick a name from the list or type a new one, then click Save.
    3. 
          
  3. Type the same name on two cards to join them into one person.
    4. 
          
  4. A wrong face in a card? Click the ✕ on that face. A card that is not a person? Use Remove group.

          
Naming works from the Photos page too: open a photo and name the face right there, or select several photos and name them all at once.

          
Don’t know someone in a photo? You never have to name them. Open the photo and click Skip under their face, and Memory Lane stops asking. When you name a photo from the selection bar and it has several faces, the name goes on the photo itself, so nothing is left to untangle.

          
Someone in the photo has no face box (turned away, small, or hidden)? Open the photo and type or choose their name in Add another person…, then click Add. The ✕ next to a name removes it again.

        
Find a photo
    
          
  • Type in the search box: a name, a year, a month, a place (“montana”), or what is in the picture (“beach”, “birthday”).
    • 
          
  • Click a tag button under the search box to see only that tag.
    • 
          
  • Use the kind list to show only Photos, Screenshots, Videos or iPhone photos.
    • 
          
  • The Person list shows one person’s photos.

        
Fix a tag, a name or a file name
    
          
  • One photo: click it. You can add or remove tags, rename the file, fix a face’s name, and see where it was taken.
    • 
          
  • Sort a group: click a tag button (like kids) to see just that group, click Select photos, pick the ones that belong together, type a new tag and/or a person's name, and click Apply & finish. Only the photos you picked change; the rest of the group stays as it is.
    • 
          
  • Many photos: click Select photos, click the pictures, then type a tag or name, rename them, or move them. Click Apply & finish when you are done.
    • 
          
  • Undo a rename: Tools → Undo last rename.

        
Delete photos and get them back
    
          
  • Select the photos and click Delete. They go to a trash folder inside the library; nothing is erased yet.
    • 
          
  • Changed your mind? Click Deleted photos, select them and click Restore.
    • 
          
  • Only Empty trash erases them for good, and Memory Lane asks first.

        
Screenshots
    
          
  • Choose Screenshots in the kind list to see only those.
    • 
          
  • Select some, add a tag like “receipts”, and click Apply & finish. Memory Lane offers to file them into a folder, or move real photos into your normal Photos folders.

        
Look-alikes
    
          
  • Open Look-alikes to compare a set-aside photo with the one already in your library.
    • 
          
  • Pick which to keep. Delete both is there too. Nothing is erased for good until you empty the trash.

        
Add new photos later
    
          
  • Put new photos in one of your photo folders and click Organize everything again. It only handles what is new.
    • 
          
  • Want it hands-free? Settings → Automatic weekly run → pick a day and time → Turn on.

        
Places and “Show on map”
    
          
  • Photos taken with location turned on show the nearest town, for example “West Yellowstone, Montana”. A yellow 📍 tag on the picture shows the town, and you can search by it. If a photo has no location, or the wrong one, open the photo, type it in the box under the date, and click Save place.
    • 
          
  • It is worked out on your computer; nothing is sent anywhere. “Show on map” opens the map only when you click it.
    • 
          
  • Photos with no location stored (screenshots, location turned off) simply show no place.

        
If something goes wrong
    
          
  • A yellow notice says an add-on is missing: close Memory Lane and run Memory Lane Setup again.
    • 
          
  • It seems stuck: click Pause, then start the step again. It picks up where it left off.
    • 
          
  • Windows says “protected your PC” during Setup: click More info, then Run anyway.
    • 
          
  • Need help? Send the file memorylane.log from the .photokeeper folder in your user folder.
