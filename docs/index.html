What it does

  • Finds the photos on your computer and gathers them into one clean place
  • Sorts them by date and sets aside the extra copies
  • Helps you name the people and see where each picture was taken
  • Stays on your computer. Nothing is uploaded

How to install

  1. Click Download Memory Lane. When it finishes, choose Open (or Keep, then open the file).
  2. If Windows shows a blue box that says “Windows protected your PC,” click More info, then Run anyway.
  3. Follow the steps on screen. Memory Lane opens when it finishes.

Windows shows the blue box for any new program it has not seen before. Memory Lane is safe to run.
