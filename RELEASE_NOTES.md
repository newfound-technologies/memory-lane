**What's new:** A photo whose file is missing can now be deleted, so empty gray tiles no longer get stuck.

**To install**
1. Download **Memory-Lane-Setup.exe** below (under Assets) and double-click it.
2. Windows may show a blue "Windows protected your PC" screen. This is normal for new programs. Click **More info**, then **Run anyway**.
3. Follow the steps. Your original photos are never changed.

**Updating?** Close Memory Lane first, then run the new installer. Your library and photos are not touched.
