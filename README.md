# Memory Lane

A private family photo organizer for Windows. It gathers photos from your folders, removes duplicates, sorts them, tags them, finds people and places, and files everything into a clean library. Your original photos are never changed.

## Download

**[Download the newest Memory Lane installer](https://github.com/newfound-technologies/memory-lane/releases/latest/download/Memory-Lane-Setup.exe)**

Double-click the file you download. Windows may show a blue "Windows protected your PC" screen, which is normal for new programs: click **More info**, then **Run anyway**.

All versions and what changed: [Releases](https://github.com/newfound-technologies/memory-lane/releases).
